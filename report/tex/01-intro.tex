\chapter*{\textbf{ВВЕДЕНИЕ}}
\addcontentsline{toc}{chapter}{\textbf{ВВЕДЕНИЕ}}

Компилятор — это программа, переводящая написанный на языке программирования текст в набор машинных кодов.
Целью данного курсового проекта является разработка компилятора для языка B.

В ходе выполнения курсового проекта необходимо решить следующие основные задачи:
\begin{itemize}
	\item провести анализ предметной области;
	\item разработать блок лексического и синтаксического анализа с явным построением дерева разбора для заданного исходного кода;
	\item разработать блок семантического анализа и генерации кода LLVM IR.
\end{itemize}
